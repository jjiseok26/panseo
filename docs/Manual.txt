# 판서 사용 설명서
화면 위에 그림을 그리거나, 필요한 부분을 캡처해 설명할 때 사용하는 도구입니다. 설치 없이 실행 파일 하나로 사용할 수 있습니다.

## 1. 처음 시작하기
① 프로그램을 실행하면 ‘판서’ 동그라미 버튼이 화면에 나타납니다. 클릭하면 메뉴가 열립니다.
② 메뉴는 마우스 포인터 효과 → 판서 및 그리기 → 빠른 도구 및 편집 순서입니다.
③ 동그라미 또는 메뉴의 제목표시줄 빈 공간을 잡고 원하는 위치로 옮길 수 있습니다.
④ 메뉴의 ─ 버튼으로 접습니다. 트레이 아이콘은 작업표시줄 오른쪽에 있으며, 보이지 않으면 숨겨진 아이콘 펼치기(∧)를 확인하세요.
⑤ 프로그램을 완전히 끝내려면 트레이의 ‘판서’ 아이콘을 우클릭하고 ‘프로그램 종료’를 누릅니다.

## 2. 마우스 위치 강조하기
하이라이트: 커서 주위를 둥글게 강조합니다. / 레이저 점: 작은 빛으로 가리킵니다.
스포트라이트: 커서 주변을 제외한 화면을 어둡게 합니다. / 타겟 링: 커서를 고리로 표시합니다.
• Ctrl+F5 하이라이트 · Ctrl+F6 레이저 · Ctrl+F7 스포트라이트 · Ctrl+F8 타겟 링 · Ctrl+F9 효과 끄기
• ‘크기’ 슬라이더와 색상 버튼으로 모양을 조절합니다. ‘클릭 파동’은 클릭한 위치에 퍼지는 고리 효과입니다.
• 포인터 효과만 켜져 있으면 아래 프로그램을 평소처럼 클릭하고 스크롤할 수 있습니다.

## 3. 화면에 그리기
① 펜·형광펜·화살표·사각형·원·직선 중 도구를 고릅니다.
② 화면에서 마우스 왼쪽 버튼을 누른 채 움직여 그립니다. 글자 도구는 원하는 위치를 클릭한 뒤 입력합니다.
③ 색상 버튼과 ‘굵기’ 슬라이더로 글씨와 도형을 조절합니다.
④ 글자는 Enter로 완료하고, Shift+Enter로 줄을 바꾸며, Esc로 입력을 취소합니다.
⑤ 일반 프로그램을 다시 조작하려면 Ctrl+M을 누르세요. Esc도 판서 모드를 끝낼 수 있습니다.
• Ctrl+P 펜 · Ctrl+H 형광펜 · Ctrl+A 화살표 · Ctrl+R 사각형 · Ctrl+O 원 · Ctrl+L 직선 · Ctrl+T 글자 · Ctrl+E 지우개
• Ctrl+1 빨강 · Ctrl+2 노랑 · Ctrl+3 초록 · Ctrl+4 파랑 · Ctrl+5 흰색 · Ctrl+6 검정
• Ctrl+Z 되돌리기 · Ctrl+Y 다시 실행 · Ctrl+Delete 전체 지우기
• 도구·색상·편집 단축키는 메뉴가 열려 있거나 판서 중에 사용합니다. 글자를 입력하는 동안에는 입력창의 편집 단축키가 우선합니다.

## 클릭으로 동그라미 번호 넣기
① 그리기 도구에서 ‘① 번호’ 또는 Ctrl+N을 선택하세요.
② 화면을 한 번 클릭할 때마다 동그라미 안에 1, 2, 3…이 표시됩니다.
③ 색상과 굵기 슬라이더로 표시의 색과 크기를 조절합니다.
④ 다른 도구를 사용하거나 다른 모니터로 옮겨도 번호가 이어집니다. ‘번호 1부터’ 버튼은 이미 찍은 표시를 남기고 다음 번호만 1로 초기화합니다. 전체 지우기를 해도 1부터 시작합니다.
⑤ Ctrl+Z / Ctrl+Y로 표시를 되돌리거나 다시 실행할 수 있습니다. 다음 번호는 유지되므로 1부터 다시 찍으려면 초기화 버튼을 누르세요.
캡처 편집 창에서도 번호 도구를 사용할 수 있으며 각 편집 창은 별도로 1부터 시작합니다.

## 4. 화면 확대/축소 모드
① ‘확대/축소’ 버튼 또는 Ctrl+F12를 누릅니다. 마우스가 있는 모니터의 현재 화면을 띄웁니다.
② 마우스 휠을 위로 굴리면 확대, 아래로 굴리면 축소합니다. 마우스가 가리키는 곳을 중심으로 확대됩니다. 범위는 기본 화면의 25~800%입니다.
③ 왼쪽 버튼으로 드래그해 확대된 화면의 다른 부분을 봅니다.
④ 더블클릭, 숫자 0 또는 ‘100%’ 버튼으로 기본 크기로 되돌립니다.
⑤ Esc, Ctrl+M, Ctrl+F12 또는 ‘닫기’로 나옵니다.
이 모드는 들어가는 순간의 화면을 자세히 살펴보는 기능입니다. 동영상이나 화면 변화는 갱신되지 않습니다. 아래 프로그램을 클릭하려면 확대 모드를 끝내세요.

## 5. 필요한 영역 캡처하고 편집하기
① Ctrl+F10 또는 ‘캡처 저장’을 누릅니다.
② 화면에서 저장할 영역을 드래그합니다. 반대 방향으로 드래그해도 됩니다. Esc 또는 우클릭은 선택 취소입니다.
③ 편집 창에서 펜·사각형·원·화살표·글자 도구로 설명을 추가합니다. Ctrl+Z / Ctrl+Y로 편집을 되돌리거나 다시 실행할 수 있습니다.
④ 편집 창의 ‘저장’ 또는 Ctrl+F10을 누르고 파일 이름과 위치를 선택합니다. 기본 폴더는 내 사진\PanseoScreenshots입니다.
⑤ PNG 이미지로 저장하며 클립보드에도 복사를 시도합니다. 확대해서 보더라도 저장 이미지는 캡처 원본 해상도를 유지합니다.

## 6. 캡처를 화면 위에 고정하기
① Ctrl+F11 또는 ‘영역 캡처 고정’을 누른 뒤 영역을 드래그하면 캡처 이미지가 항상 맨 위에 뜹니다.
② 캡처 편집 창에서 ‘화면 고정’ 또는 Ctrl+F11을 누르면 편집한 이미지가 고정됩니다.
③ 이미지 위에서 휠을 굴려 확대/축소합니다. 확대 후 Ctrl을 누른 채 왼쪽 버튼으로 드래그하면 이미지 안에서 위치를 옮길 수 있습니다.
④ Ctrl 없이 이미지를 잡고 드래그하면 고정 창 전체가 이동합니다. 더블클릭 또는 숫자 0은 기본 크기로 되돌립니다.
⑤ 이미지를 우클릭하면 ‘저장하기’, ‘닫기’가 나옵니다. 저장은 현재 확대 배율과 관계없이 편집한 전체 이미지를 원본 해상도로 저장합니다.

## 7. 자주 쓰는 단축키
Ctrl+F1 메뉴 열기/닫기 · Ctrl+F2 판서 켜기/끄기 · Ctrl+F3 포인터 효과 켜기/끄기 · Ctrl+F4 칠판 배경
Ctrl+M 일반 마우스 모드 · Ctrl+F10 영역 캡처/편집 창 저장 · Ctrl+F11 캡처 고정 · Ctrl+F12 화면 확대/축소
Ctrl+Z 되돌리기 · Ctrl+Y 다시 실행 · Ctrl+Delete 전체 지우기 · Esc 취소/모드 종료

## 8. 업데이트와 도움이 필요할 때
프로그램은 시작 시와 실행 중 4시간마다 새 버전을 확인합니다. 다운로드가 완료되면 작업을 마치고 트레이 메뉴에서 프로그램을 종료하세요. 다음 실행부터 새 버전이 적용됩니다.
트레이 우클릭 → ‘업데이트 확인’으로 직접 확인할 수 있습니다. 인터넷이 연결되지 않아도 판서 기능은 계속 사용할 수 있습니다.
제목표시줄의 ‘업데이트’와 ‘설명서’ 버튼은 최소화 버튼 왼쪽에 있습니다. 이 설명서는 제목표시줄의 ‘설명서’ 버튼과 트레이 메뉴에서 언제든 열 수 있으며 인터넷 연결이 필요하지 않습니다.
