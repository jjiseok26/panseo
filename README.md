# 🖥️ Panseo (판서 및 화면 마우스 포인터 도구) - 포터블 에디션

수업, 강의, 프레젠테이션, 영상 녹화 등을 위해 제작된 **윈도우 전용 플로팅 동그라미 판서 & 마우스 포인터 도구**입니다.  
설치 과정 없이 단일 실행 파일(`.exe`) 하나로 어디서나 즉시 실행되는 **완전 무설치 포터블(Portable)** 소프트웨어입니다.

---

## 🖥️ 듀얼 & 멀티 모니터 완벽 지원 (Per-Monitor V2)
- **독립 1:1 모니터 오버레이**: 듀얼 모니터 환경에서 각 모니터의 해상도나 DPI 스케일링(100%, 125%, 150% 등)이 달라도 마우스 포인터가 1픽셀의 오차 없이 마우스 커서를 자석처럼 정확히 따라갑니다.
- **모니터 간 자유로운 이동**: 마우스가 1번 모니터에서 2번 모니터로 이동하거나 다시 돌아오더라도 즉시 감지하여 정확한 위치에 포인터와 클릭 파동, 스포트라이트를 표시합니다.
- **두 모니터 모두 판서 지원**: 주 모니터뿐만 아니라 보조 모니터에서도 화살표, 도형, 펜, 글자 입력을 자유롭게 할 수 있습니다.
- **디스플레이 설정 자동 감지**: 모니터를 추가로 연결하거나 해상도를 변경해도 자동으로 감지하여 오버레이 창을 최적 재배치합니다.

---

## 🎨 로고 & 아이콘
- **모던 파비콘**: 인디고-바이올렛 그라데이션 바탕의 고화질 아이콘이 실행 파일(`.exe`) 및 트레이 아이콘으로 적용되었습니다.
- 화면에 떠 있는 플로팅 동그라미 및 메뉴 창 헤더에 깔끔한 판서 아이콘이 적용되어 있습니다.

## 🌟 새로운 플로팅 동그라미 & 트레이 인터페이스

### 1. 🟣 플로팅 동그라미 버튼 (Floating Circle FAB)
- 화면 위에 **지름 54px 크기의 예쁜 보라-인디고 그라데이션 동그라미 버튼(`✏️`)**이 항상 떠 있습니다.
- **자유로운 드래그 이동**: 마우스로 잡고 화면 어디든 원하는 곳으로 쉽게 끌어다 놓을 수 있습니다.
- **원클릭 메뉴 열기**: 동그라미를 **마우스로 클릭**하면 메인 판서 & 포인터 메뉴 패널이 스르륵 나타납니다!
- **스크롤 없는 메뉴**: 포인터 효과 → 판서 및 그리기 → 빠른 도구 및 편집 순으로 좁은 세로 메뉴에 모두 표시하며, 작은 화면에서는 메뉴 전체 크기를 자동 조절합니다.
- **간편한 닫기**: 도구 선택 시 자동으로 닫히거나, 상단의 `─` 또는 `✕` 버튼을 누르면 컴팩트한 플로팅 동그라미로 복귀합니다.

### 2. 🔔 작업표시줄 시스템 트레이 아이콘
- 프로그램이 실행되면 작업표시줄 우측 하단 트레이 영역에 아이콘이 상시 표시됩니다.
- **트레이 아이콘 클릭/더블클릭**: 언제든 판서 메뉴를 즉시 열거나 닫을 수 있습니다.
- **트레이 우클릭 메뉴**:
  - ✏️ 판서 메뉴 열기 / 닫기
  - 🎯 마우스 포인터 효과 토글 (`Ctrl+F3`)
  - 🖊️ 판서 모드 토글 (`Ctrl+F2`)
  - ⬛ 칠판 모드 토글 (`Ctrl+F4`)
  - ℹ️ Panseo 정보
  - ❌ 프로그램 완전 종료

## ✨ 핵심 기능

### 🎯 1. 마우스 포인터 효과 (화면 상시 유지)
- **일반 모드 관통(Click-Through)**: 마우스 효과가 켜진 상태에서도 화면 아래의 웹 브라우저, PPT, 유튜브 등을 평소처럼 클릭/스크롤할 수 있습니다.
- **다양한 모양 선택**:
  - 🟡 **원형 하이라이트**: 반투명 형광 원으로 커서 위치 강조 (강의/수업 시 마우스 위치 집중)
  - 🔴 **레이저 포인터**: 선명한 중심 코어와 외곽 Glow 발광 레이저
  - 🔦 **스포트라이트**: 마우스 주변만 밝게 비추고 나머지 화면을 70% 어둡게 마스킹
  - 🎯 **타겟 링**: 도넛 모양의 정밀 조준 링
  - 🚫 **끄기**: 마우스 효과 비활성화
- **크기 및 색깔 실시간 변경**:
  - 슬라이더를 통해 포인터 지름(20px ~ 160px)을 실시간 조절
  - 원클릭 퀵 색상 팔레트 (형광 노랑, 빨강, 초록, 파랑, 보라, 주황)
- **클릭 파동 효과 (Ripple)**: 마우스 좌클릭/우클릭 시 클릭 지점에서 링이 부드럽게 퍼져나가는 시각 피드백 제공

---

### ✏️ 2. 화면 판서 및 직관적인 모양 그리기 버튼
- ➡️ **화살표 (Arrow)**: 드래그 한 번으로 반듯한 직선 끝에 깔끔한 화살표 머리가 달린 방향 지시 화살표를 한 번에 생성
- 🔲 **사각형 (Rectangle)**: 영역 강조 박스 드래그 그리기
- ⭕ **원/타원 (Ellipse)**: 중요한 단어나 그림에 동그라미 강조
- ➖ **직선 (Line)**: 반듯한 밑줄 및 구분선
- ✏️ **자유 펜 & 🖍️ 형광펜**: 손글씨 필기 및 반투명 형광펜 강조
- 🧽 **지우개 (Eraser)**: 클릭한 선이나 도형을 개별 삭제
- 🎨 **선 굵기 & 색상 조절**: 슬라이더로 굵기 조절, 원클릭 팔레트로 색상 변경

---

### 🔤 3. 글자 넣기 (텍스트 입력)
- 메뉴의 **`🔤 글자 넣기`** 버튼을 누른 후 화면 원하는 곳을 마우스로 클릭하면 텍스트 입력창이 나타납니다.
- 글자를 입력하고 **`Enter`**를 누르면 화면 해당 위치에 선명한 텍스트로 각인됩니다 (`Esc` 키로 취소 가능).

---

### 🛠️ 4. 퀵 도구 & 편의 기능
- ⬛ **칠판 모드 (`Ctrl+F4`)**: 어두운 칠판 배경을 깔아 자유롭게 판서 가능
- ↩️ **되돌리기 (`Ctrl+Z`)** / ↪️ **다시 실행 (`Ctrl+Y`)**
- 🧹 **전체 지우기 (`Ctrl+Delete`)**: 클릭 또는 단축키로 모든 판서 내용 삭제
- 📸 **영역 캡처 및 편집 (`Ctrl+F10`)**: 원하는 영역을 드래그하면 캡처 편집 창이 열립니다. 펜·사각형·원·화살표·글자를 추가한 뒤 저장하거나 화면에 고정할 수 있습니다. PNG 저장 대화상자의 기본 위치는 `내 사진\PanseoScreenshots`이며, 저장한 이미지는 클립보드에도 복사됩니다.
- 📌 **영역 캡처 고정 (`Ctrl+F11`)**: 영역을 드래그하면 항상 맨 위에 떠 있는 고정 캡처를 만듭니다. 캡처 편집 중에는 현재 편집 내용을 고정합니다. 이미지를 드래그해 이동하고, 우클릭 메뉴의 **저장하기 / 닫기**를 사용할 수 있습니다.
- **창 이동**: 메인 메뉴의 제목표시줄은 빈 공간에서도 드래그할 수 있습니다. 캡처 편집 창도 제목표시줄로 이동합니다.
- **영역 선택 취소**: Esc 또는 마우스 우클릭.

## 🚀 포터블 실행 방법

설치가 전혀 필요 없으며, 아래 파일 중 하나를 더블 클릭하여 실행하시면 됩니다:
- [**panseo_portable.exe**](https://github.com/jjiseok26/panseo/releases/latest/download/panseo_portable.exe) 또는 [**Panseo.exe**](https://github.com/jjiseok26/panseo/releases/latest/download/Panseo.exe)
- **Panseo_실행.bat** (소스 폴더에서 실행)


## 자동 업데이트 및 배포

- 실행 시 및 실행 중 4시간마다 GitHub의 최신 정식 릴리스를 확인합니다. 네트워크 연결이 없어도 프로그램은 계속 동작합니다.
- 새 파일의 SHA-256, 파일 크기, 내장 버전을 확인한 뒤 내려받습니다. 현재 판서 작업을 강제로 종료하지 않으며, 프로그램을 정상 종료하면 실행 파일을 교체하여 다음 실행부터 새 버전이 적용됩니다.
- 업데이트 교체 시 기존 실행 파일은 `.update-backup`으로 보관합니다. 폴더 쓰기 권한이나 파일 잠금 때문에 교체할 수 없으면 기존 파일을 유지하고 다음 종료 때 다시 시도합니다.
- 트레이 우클릭 → **업데이트 확인**으로 직접 확인할 수도 있습니다.
- 업데이트 기록: `%LOCALAPPDATA%\Panseo\Updates\<설치별 폴더>\update.log`
- 최초에는 [최신 릴리스](https://github.com/jjiseok26/panseo/releases/latest)에서 업데이트 기능이 포함된 실행 파일을 받아 실행해야 합니다.

`main` 브랜치에 변경 사항을 올리면 GitHub Actions가 `1.0.<실행번호>` 버전으로 빌드·검사하고, 통과한 실행 파일과 ZIP을 Releases에 자동 배포합니다. 로컬 빌드 및 검사는 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Release.ps1`로 실행할 수 있습니다.


## 화면 및 고정 캡처 확대/축소

- 메뉴 **확대/축소** 또는 **Ctrl+F12**: 마우스가 있는 모니터의 진입 순간 화면을 띄워 휠로 25~800% 확대/축소합니다. 드래그로 이동하고 더블클릭·0·100% 버튼으로 초기화합니다. Esc·Ctrl+M·Ctrl+F12로 나옵니다. 정지 화면을 살펴보는 기능이므로 동영상이나 화면 변화는 갱신되지 않습니다.
- **고정 캡처** 위에서도 휠로 확대/축소합니다. Ctrl+드래그는 이미지 안에서 이동, 일반 드래그는 창 전체 이동입니다. 더블클릭 또는 0으로 초기화합니다. 저장은 배율과 관계없이 전체 원본 이미지를 저장합니다.
- 메뉴와 트레이의 **사용 설명서**에서 인터넷 없이 모든 사용법과 단축키를 볼 수 있습니다. [설명서 원문](docs/Manual.txt)
- 트레이의 **판서** 아이콘은 실행 파일 안에 내장되어 있어 외부 아이콘 파일이 필요하지 않습니다.


## 클릭으로 번호 넣기

- **① 번호 (Ctrl+N)** 도구를 선택하고 화면을 클릭할 때마다 동그라미 안에 1, 2, 3…이 표시됩니다. 색상과 굵기 설정을 사용하며 되돌리기·다시 실행·지우개를 적용할 수 있습니다.
- **번호 1부터**는 기존 표시를 남기고 다음 번호를 1로 되돌립니다. 전체 지우기도 번호를 초기화합니다. 번호는 도구를 바꾸거나 모니터를 옮겨도 이어집니다. 되돌리기로 표시를 제거해도 다음 번호는 유지됩니다.
- 캡처 편집 창에서도 **번호** 도구를 사용할 수 있으며 각 편집 창은 1부터 시작합니다.
- **업데이트**와 **설명서** 버튼은 제목표시줄에서 최소화 버튼 왼쪽에 있습니다.
- 플로팅 동그라미의 검은 그림자 효과를 제거했습니다. 배포 파일명은 **panseo_portable.exe**입니다.
